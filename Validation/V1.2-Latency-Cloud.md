Reproduce the service suite from repository root:

```bash
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy \
  NO_PROXY=127.0.0.1,localhost python -m unittest discover -s ControlService -v
cd ControlService
node --test test_client_panel.js test_content_panel.js test_operator_panel.js
```

The onboarding baseline (897 tests) had 11 failures and 4 errors. Codex/voice
fixtures used mocked inference but still performed public catalog discovery;
workers timed out and unfinished teardown contaminated later tests. Those
fixtures now isolate catalog enrichment, which is tested separately by the
content suites. This changes test dependencies, not production discovery,
permissions, proposals or voice behavior. Loopback proxy bypass is necessary
in this cloud environment; the first unadjusted run also sent local HTTP
through the external proxy. All relevant suites were rerun after correction.

For the browser check, start a **dedicated scratch service**, build the web
runtime, then run `python Tools/Smoke-V12-Cloud.py`. It requires installed
Playwright and Chromium (`/usr/bin/chromium`) and defaults to local port 8767;
`MATRIX_SMOKE_URL` can select another dedicated local service. Never point it
at a current wearer session or a service hosting an existing world.

Raw synthetic prompt assembly samples are retained in
`Validation/v1.2/context-before.json` and `context-after.json`. Each includes
its source identities and dirty marker, runtime, scene size, settings, 8 workloads × 60
warm samples, p50/p95, bytes, errors and retries. Against v1.1.0 the compact
builder reduces envelope bytes 52–82%. The before report records an exploratory
uncommitted tracing tree explicitly; the after report uses clean compact-context
commit `f16c2a266f7340d4ace8711e43fabbf4c636acac` against the exact v1.1 builder. Assembly is fractions of a millisecond;
some small contexts get slightly slower. These samples do **not** demonstrate
model inference, tool-call counts, end-to-end latency or wearer improvement.
The 4 KiB envelope and 1 ms assembly diagnostics are engineering observations,
not agreed product or wearer latency targets.
