# Issue #150 — Matrix panorama environment validation

This milestone adds a world-level equirectangular panorama to the existing Matrix WebXR scene. The panorama is a registered image dependency, not geometry or a physical-room measurement. This record separates automated checks, a live desktop browser run, and Quest wearer evidence.

## Automated checks

- ControlService: `python -m unittest discover -s ControlService -p test_*.py -q` — **868/868 passed**. Focused tests cover PNG validation and digest registration, exact typed action receipts, stale revision and mismatched receipt rejection, the private MCP bridge, HTTP image bytes, and PC checkpoint dependency failure.
- WebRuntime: `npm test` — **657/657 passed**. Focused tests cover set/change/get/remove with stable object IDs, Undo/Redo, browser and PC restoration, browser archives, missing assets, old-world recovery when the panorama catalog fails, AR suppression, checksum/size/dimension preflight, timeout, and late decode cleanup. Delayed-preflight regressions verify that a successful direct edit cannot be overwritten by a queued panorama command or browser checkpoint restore, that stale commands return failed receipts, and that an offline browser restore remains available. XR entry is blocked before native session setup while a world restore is active.
- `npm run build` — passed. Vite reported its existing large chunk warning.
- `python -m unittest Tools.test_build_webxr_release -q` — **3/3 passed**; `git diff --check` — passed.

## Quest and release boundary

The connected Quest was forwarded to the isolated review service at `http://127.0.0.1:18961/web/`. The wearer restored `panorama-150-desktop-check` and reported that **Azimuth B surrounds the block in VR**. In AR, the wearer clarified that the **normal physical room and walls are visible, while the panorama is absent**. The live service reported an AR presentation with 38 room planes, and retained the Azimuth B descriptor, full digest, and 90° yaw. This is the intended passthrough behavior. No origin recovery step was reported. Device information read from the connected headset: Quest 3, Android 14, Quest Browser `152.0.0.44.30.1069357998`. These are wearer visual observations plus service state, not measured physical alignment.

The source release builder includes this contract documentation and compiled Web runtime. Its default public package does not include the private panorama catalog, browser storage, or PC checkpoints. The final v1.0 frozen-package gate in #152 still needs an explicitly reviewed panorama and matching isolated data, plus its own exact-package Quest VR/AR observations.
