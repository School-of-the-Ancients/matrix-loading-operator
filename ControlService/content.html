Content library

Add prepared props to the running Matrix app, then ask the Operator to use them. New Asset Store content still needs preparation in Unity. Start with the guide below.

How this works

The benefit: prepare a prop pack once in Unity, then install it in Matrix without rebuilding or reinstalling the APK for each compatible pack. You can add props while the app is running and use the same AI placement, Undo, and scene save/restore tools.

  1. For an existing pack: search the configured catalogs below. On Quest, choose the Android result and select Install prefab pack.
  2. Keep Matrix open and connected. Wait for ready under Downloads and installation. This confirms the app loaded the props; it does not place them in the room.
  3. Return to the room panel and ask the Operator to place an installed prop. Review and apply its proposal, then try editing it or using Undo.
  4. After restarting Matrix, install the same pack again before restoring a scene that uses it. Verified cached files are reused when available.
New Asset Store content, rebuilds, and AI limits

Asset Store preparation: add the package to the checklist below, acquire it through Unity, import and inspect it in the Editor, then export supported prefabs as a Matrix content pack. Configure that pack's catalog on the PC before searching and installing here. Adding a URL or changing a checklist status does not perform these steps.

What works today: static props made from supported meshes, materials, and basic colliders. A whole Asset Store package is not automatically compatible. Animated characters, downloaded scripts, custom shaders, and complete Unity projects are not supported by this first loader.

What needs a build: a compatible new prop needs a content pack export for the app's platform and exact Unity version. New application code or behavior needs a new app/APK build. One initial updated APK is needed to add this loader.

AI instructions: the Operator receives the installed asset list and can propose placement and edits using those assets. It can see recent catalog search candidates, but it does not acquire, import, export, install, or generate content for you.

Providers

Providers are configured catalogs or generation workers. Catalog search covers these sources, not the entire Unity Asset Store.

Content categories and availability

Categories organize search results and preparation work. A category such as animations or behaviors does not mean the running app can load that content; this loader currently installs supported static prefab packs.

Downloads and installation

A prefab pack must match the connected app's platform and Unity version. Installing adds choices to the library; place them using a reviewed proposal. After restarting the app, reinstall the same pack before restoring scenes that use it.

Unity asset preparation checklist

Track manual work on an Asset Store package or local .unitypackage. Complete each step in Unity, then select its status and choose Record completed step. Recording a status only updates this checklist.

What do the statuses mean?
StatusWhat you have done
queuedAdded a package to prepare. No acquisition, download, or import has happened here.
acquiredObtained the package through its licensed source; it is available to import in Unity.
importedImported the package into a Unity Editor project. It still needs compatibility review and pack export.
exportedBuilt a Matrix content pack from supported prefabs. Configure its catalog and install the pack separately.
cancelledStopped preparing this package.
failedA preparation step failed and needs attention.

Installed / ready is separate: only a successful install under Downloads and installation confirms the connected app can use the props. Marking a package exported does not install it.
