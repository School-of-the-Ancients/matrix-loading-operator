# Prebuilt Professor avatars

These runtime VRM 1.0 avatars are stylized historical interpretations created for
School of the Ancients using VRoid Studio stock meshes/textures and locally authored
portrait details. They are not verified likenesses or official pixiv products.

The repository's MIT code license does not relicense pixiv's stock content.
Use the embedded VRM Public License 1.0 terms together with the
[VRoid Studio guidelines](https://vroid.com/en/studio/guidelines). The release permits
avatar use, redistribution and modification under those terms; commercial usage
remains personal non-profit in the embedded metadata. No paid third-party assets,
Riko models, voice samples, editable `.vroid`/`.blend` sources or private seed indexes
are included here.

The models can be used as runtime characters. Shipping a character-creation tool
that generates models from VRoid meshes/textures is a different use covered by
pixiv's separate creation-tool provision. Editable seed reuse in this project is
a private local authoring workflow, not a bundled public generator.
