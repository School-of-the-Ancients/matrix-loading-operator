# Matrix v1.3 Professor release candidate

The owner selected the current embodied Professor implementation for the next
release on October 24, 2026. `v1.3.0-rc.1` is a new candidate; it does not replace
the frozen v1.2 tag or assets. The generated release manifest pins the exact
Matrix and School commits, build tools, file hashes and extracted-bundle checks.

## Included experience

- Ask a first question to create a School lesson and attach a matching avatar.
- Switch between Professor conversation and direct Matrix Operator input.
- Continue a short, exhibit-led lesson while delegated Blender work runs.
- Play teacher-specific local speech with lip-sync, idle motion and pointing.
- Select a named part or exact virtual object point with A/X; B/Y clears it.
- Send a marked virtual-view image with a question, without passthrough capture.
- Read persistent Professor-only messages in the floating AR/VR panel.
- Reuse registered exhibits and avatars; direct creation does not require previews.

The bundle includes the pinned School UI/API and six original stylized scholars.
The user's imported Leonardo/Riko avatars, private exhibit library, saved lessons,
recordings and voice samples are not redistributed. Local speech weights and
Blender/Codex installations remain external prerequisites. The paired launcher
uses the owner's selected Full access policy, requires Codex 0.159.0 and refuses
to replace occupied 8765/3110 services. See `RELEASE-README.md` inside the bundle.

## Evidence and limits

The wearer confirmed the integrated Quest demo, responsive AR after the raycast
fix, part description, and a cleaner floating transcript whose text remains
visible. The two additional invention loads have successful runtime receipts.
These observations belong to the running development build, not an extracted
release-candidate headset test. The existing acceptance record retains each
observation and unresolved check; no broad H01-H10 pass is claimed.

The candidate build runs isolated UI/API/asset and hosted-world checks after ZIP
extraction. Native full-duplex speech, model art quality, complete device input
coverage, and full save/reopen/recovery acceptance remain open. Versioned build
outputs, checksums and the companion School identity are attached to the release.
