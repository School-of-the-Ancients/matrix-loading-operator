## Start the paired release

Extract the ZIP into its own folder. Install the documented Python, Node and
native Codex prerequisites. Run `Start-Professor.ps1`; it starts the local
services on 8765/3110 and leaves existing occupied ports alone. Run
`Tools/Setup-ProfessorVoices.ps1` for Kokoro voices and `Setup-LocalSpeech.ps1`
for local transcription. The optional Riko voice additionally needs its own
SoVITS service/reference; it is not required for the other voices.

For Quest, keep USB connected, run `python Tools/connect_professor_quest.py`,
and open `http://127.0.0.1:8765/web/` in Quest Browser. Select Professor and ask
a learning question. For complete controls and fresh-world/conversation behavior,
use [the voice guide](Professor-Voice.md) and [task/transcript guide](Professor-Delegation.md).

Reproduce the same pairing from reviewed checkouts with:

```powershell
python Tools/Build-WebXR-Release.py --version v1.3.0-rc.1 `
  --commit e0135516f9357877d0a1657181fb001abcfe7640 `
  --professor-repo C:\path\to\sota-professor `
  --professor-commit a6c2934f267463714b72a14a980d1c472a798aaa `
  --output C:\path\to\new-release-output
```

Use the builder at the tagged source and a new output folder. This creates a
local reproduction; it does not replace the published package or private data.

## Included experience

- Ask a first question to create a School lesson and attach a matching avatar.
- Switch between Professor conversation and direct Matrix Operator input.
- Continue a short, exhibit-led lesson while delegated Blender work runs.
- Play teacher-specific local speech with lip-sync, idle motion and pointing.
- Select a named part or exact virtual object point with A/X; B/Y clears it.
- Send a marked virtual-view image with a question, without passthrough capture.
- Read persistent Professor-only messages in the floating AR/VR panel.
- Reuse registered exhibits and avatars; direct creation does not require previews.

The bundle includes the pinned School UI/API and six original stylized scholars.
The user's imported Leonardo/Riko avatars, private exhibit library, saved lessons,
recordings and voice samples are not redistributed. Local speech weights and
Blender/Codex installations remain external prerequisites. The paired launcher
uses the owner's selected Full access policy, requires Codex 0.159.0 and refuses
to replace occupied 8765/3110 services. See `RELEASE-README.md` inside the bundle.
