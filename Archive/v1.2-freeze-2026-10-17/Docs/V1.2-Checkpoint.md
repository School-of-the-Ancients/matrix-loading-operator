## Start and use the checkpoint

1. Download and extract the ZIP into its own directory. Follow its `RELEASE-README.md` for Python, native Codex sign-in, Agent/MCP dependencies and the service launcher. Keep writable data outside the extracted bundle. Speech models and Blender are optional external prerequisites for those capabilities.
2. Open the matching `/web/` service in desktop or Quest Browser. Quest WebXR needs a secure origin; the documented USB `adb reverse` route preserves localhost. Keep the service port, browser URL and USB reverse port equal.
3. Choose **Start or resume Codex**. Before entering XR, select and apply **Reviewed** or deliberately confirm **Full access**. Reviewed uses PC review for native command/MCP approvals; Full access permits PC files/network/configured tools with automatic native approvals for that service session. Matrix world guards remain. Change policy only while the Agent is idle.
4. Select a prop, pin a fresh destination and ask Codex to move it there. Ordinary AR creation and point moves use free placement and preserve rotation/scale; they do not certify physical clearance. The **Fit to room** control and measured-fitting acceptance were explicitly deferred from v1.2. Existing explicit measured tools retain their guards.
5. **Hold for Codex** opens the same conversation from every Operator page. During a turn, **Hold to Add** adds an instruction and **Stop Turn** remains available. Expired/rejected speech keeps the editable draft and refreshes status without automatic replay. The desktop text planner remains a separate explicit workflow.
6. Use deliberate Lock/Unlock on the selected object in paused Creator Mode. Locked scenery stays selectable; Play authority remains. Save World before browser refresh or version switching, and copy any unsent draft before refreshing.

See the [Quest controls FAQ](../WebRuntime/README.md#quest-controls-faq) and [Agent permissions/review guide](../ControlService/AGENT_PORTAL.md) for detailed controls and failure handling.
