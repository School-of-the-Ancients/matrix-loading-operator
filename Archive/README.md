## Reading historical records

Archived text is preserved as written. Its old instructions, status claims and candidate identities describe their original context. Relative links between archived files retain their original layout; links to files outside this archive may need the [complete pre-cleanup snapshot](https://github.com/School-of-the-Ancients/matrix-loading-operator/tree/60ab4599752147f2e590293208bee4692965a524). That snapshot records the original location and surrounding source for every archived file.

The snapshot is commit `60ab4599752147f2e590293208bee4692965a524`, also retained by branch `archive/pre-v1.2-freeze-2026-10-17`. It includes later #207 work; **the published v1.2 source remains `858d486e9ee8507af36e2a05d78f1d34fc9ca2b0`**.

[The roadmap](../ROADMAP.md) and owning issues decide current scope. The archived October 27 runbook still supports #201; other proposals remain unselected unless the owner chooses a slice. Keep new build output in its issue/PR. Preserve useful research in the repository and link it from [RESOURCES.md](../RESOURCES.md), with its original context and sources.
